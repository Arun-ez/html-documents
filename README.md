## `whoami`

I'm a full-stack developer who enjoys working across the entire product
journey --- shaping an interface, designing APIs, connecting data, and
getting applications into production.

I work with **JavaScript, React, Next.js, Node.js, and Flutter**, and I
enjoy exploring the engineering details behind products: performance,
maintainability, developer experience, and the infrastructure that keeps
everything running.

-   🧩 I build **web and mobile applications** from the ground up.
-   ⚙️ I enjoy turning complex requirements into clean, practical
    solutions.
-   ☁️ I work across backend systems, cloud services, and deployment
    workflows.
-   ✍️ I share implementation notes and things I've learned on my [tech
    blog](https://blog.arunshaw.in).
-   🚀 I like building useful tools --- including developer-focused
    projects and reusable libraries.

> **My approach:** Make it useful. Make it reliable. Make it feel
> effortless.
